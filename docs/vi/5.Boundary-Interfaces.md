# System Boundary Interface Documentation

This document describes the system's external invocation interfaces, including CLI commands, API endpoints, configuration parameters, and other boundary mechanisms.

## Command Line Interface (CLI)

### agentwiki [PROFILE]

**Description**: Công cụ dòng lệnh (Rust, clap) sinh tài liệu kiến trúc kiểu C4 cho một repository bằng các agent CLI đã xác thực (devin, claude, codex) làm backend LLM. Điểm vào duy nhất: `main.rs` parse `Args` bằng clap, merge cấu hình theo thứ tự defaults → `~/.config/agentwiki/config.toml` (hoặc `$XDG_CONFIG_HOME/agentwiki/config.toml`) → `<project>/agentwiki.toml` → profile được chọn → CLI overrides, rồi chạy pipeline scan → research → compose → write → verify. Xử lý SIGINT/SIGTERM: tín hiệu đầu hủy mềm (kill các CLI con), tín hiệu thứ hai thoát với mã 130.

**Source File**: `src/cli.rs, src/main.rs`

**Arguments**:

- `PROFILE` (string): optional - Tên profile định sẵn trong section `[profiles.<name>]` của agentwiki.toml (project hoặc global). Profile project ghi đè profile global cùng tên; profile không tồn tại gây lỗi liệt kê các profile khả dụng.

**Options**:

- `--project-path, -p`(path): optional - Đường dẫn repository cần tạo tài liệu. (default: `.`)
- `--output-path, -o`(path): optional - Thư mục ghi cây tài liệu Markdown đầu ra. (default: `./agentwiki.docs`)
- `--config, -c`(path): optional - Đường dẫn tường minh tới file agentwiki.toml (mặc định tìm `<project>/agentwiki.toml`, fallback `agentwiki.toml` ở cwd). (default: `<project>/agentwiki.toml`)
- `--target-language`(enum {zh, en, ja, ko, de, fr, ru, vi}): optional - Ngôn ngữ viết phần prose trong tài liệu; mỗi prompt được nối thêm chỉ dẫn ngôn ngữ tương ứng, JSON keys giữ tiếng Anh. (default: `en`)
- `--model-efficient`(string): optional - Chuỗi `"<backend>:<model>"` cho các tác vụ thường (tier Efficient). (default: `devin:swe-2-medium`)
- `--model-powerful`(string): optional - Chuỗi `"<backend>:<model>"` cho reasoning nặng và fallback khi retry (tier Powerful). (default: `devin:swe-2-medium`)
- `--max-parallels`(usize): optional - Số cuộc gọi agent CLI chạy đồng thời tối đa (tối thiểu 1). (default: `2`)
- `--agentic`(flag): optional - Chế độ agentic: agent tự đọc repo ở project root thay vì nhúng code/materials vào prompt (mode=embedded là mặc định). (default: `false`)
- `--no-cache`(flag): optional - Không đọc và không ghi cache trên đĩa (`.agentwiki/`). (default: `false`)
- `--force-regenerate`(flag): optional - Bỏ qua kết quả cache, tính lại và ghi đè. (default: `false`)
- `--skip-research`(flag): optional - Bỏ qua pha research LLM; nạp `.agentwiki/research.json` đã có. (default: `false`)
- `--skip-documentation`(flag): optional - Dừng sau pha research; không sinh/ghi tài liệu. (default: `false`)
- `--dry-run`(flag): optional - Chỉ quét repo, in cấu hình hiệu lực và DAG tác vụ rồi thoát — không gọi LLM. (default: `false`)
- `--verbose, -v`(count flag): optional - Mức log lũy tiến: `-v` info, `-vv` debug, `-vvv` trace; biến môi trường `RUST_LOG` ghi đè. (default: `0 (warn)`)

**Usage Examples**:

```bash
agentwiki -p /path/to/repo -o ./docs
```

```bash
agentwiki research -p . --skip-documentation
```

```bash
agentwiki --dry-run --model-efficient claude:sonnet -vv
```

```bash
agentwiki -c custom/agentwiki.toml --agentic --force-regenerate
```

### agentwiki.toml / ~/.config/agentwiki/config.toml (cấu hình TOML)

**Description**: Giao diện cấu hình tập tin (xem như startup/config boundary). Mọi trường đều optional và merge lên defaults; section `[profiles.<name>]` định nghĩa profile chọn qua positional arg. Biến môi trường liên quan: `XDG_CONFIG_HOME` (vị trí config global) và `RUST_LOG` (ghi đè mức log).

**Source File**: `src/config.rs`

**Options**:

- `project_path / output_path / internal_path / prompts_dir`(path): optional - Đường dẫn repo, thư mục output, thư mục state nội bộ (mặc định `.agentwiki`, resolve tương đối theo project), và thư mục prompt override. (default: `. / ./agentwiki.docs / .agentwiki / None`)
- `target_language`(string enum): optional - Ngôn ngữ prose (zh|en|ja|ko|de|fr|ru|vi). (default: `en`)
- `mode`(string enum): optional - `embedded` (nhúng materials vào prompt) hoặc `agentic` (agent tự đọc file). (default: `embedded`)
- `max_parallels`(usize): optional - Độ song song tối đa của các cuộc gọi CLI. (default: `2`)
- `skip_research / skip_documentation / no_cache / force_regenerate`(bool): optional - Cờ điều khiển pipeline và cache, tương đương các flag CLI. (default: `false`)
- `[models] efficient / powerful`(string): optional - Chuỗi `"<backend>:<model>"` cho hai tier model (efficient cho tác vụ thường, powerful cho reasoning nặng/fallback). (default: `devin:swe-2-medium`)
- `[limits] daily_cap / call_timeout_s / retry_attempts / materials_char_cap / code_insights_limit / file_source_chars`(number): optional - Giới hạn vận hành: số cuộc gọi CLI/ngày, timeout mỗi cuộc gọi, số lần retry parse/validate, kích thước materials tối đa nhúng vào prompt, số file insights tối đa, số ký tự source mỗi file trong dir_summary. (default: `300 / 600 / 3 / 192000 / 25 / 500`)
- `[scan] max_depth / max_file_size / git_tracked_only / include_hidden / include_tests / excluded_dirs / excluded_files`(mixed): optional - Tùy chọn quét repo: độ sâu đệ quy, kích thước file tối đa, chỉ quét file git-tracked (dùng `git ls-files`), gồm dotfile/test, danh sách thư mục và glob file loại trừ. (default: `10 / 524288 / true / false / false / <danh sách mặc định target,node_modules,vendor,...> / <*.lock,*.log,.env,agentwiki.toml,...>`)
- `[verify] mermaid_fixer`(bool): optional - Chạy `mermaid-fixer --dry-run` trên cây output nếu binary có sẵn; nếu vắng mặt dùng heuristic nội bộ. (default: `true`)

**Usage Examples**:

```bash
max_parallels = 4\ntarget_language = "vi"\n[models]\nefficient = "claude:sonnet"\npowerful = "devin:swe-2-medium"\n[limits]\ndaily_cap = 50\n[profiles.research]\nskip_documentation = true
```

## Integration Suggestions

### CLI invocation / subprocess

Tích hợp chuẩn là gọi binary `agentwiki` như một lệnh con. Dùng `--dry-run` để kiểm tra cấu hình hiệu lực và DAG trước khi chạy thật; bắt mã thoát 130 khi bị hủy bởi SIGINT/SIGTERM.

**Example Code**:

```
#!/usr/bin/env bash
agentwiki -p "$REPO" -o "$OUT" --target-language vi --model-efficient claude:sonnet 2>&1 | tee run.log
# hoặc kiểm tra trước:
agentwiki -p "$REPO" --dry-run -v
```

**Best Practices**:

- Luôn chạy `--dry-run` trước trong CI/cron để tránh đốt quota agent CLI.
- Đặt `daily_cap` trong `[limits]` để bảo vệ hạn mức subscription; kiểm tra `.agentwiki/` (cache, quota, calls.jsonl audit) sau mỗi run.
- Không truyền biến môi trường API billing (OPENAI_API_KEY, ANTHROPIC_API_KEY...) vào tiến trình — agentwiki đã lọc các biến billing khi spawn backend, giữ nguyên sạch phía caller.
- Chạy `cargo build --release` một lần; dùng `--max-parallels` thận trọng vì mỗi slot là một subprocess CLI nặng.

### Library (Rust crate)

Crate `agentwiki` (lib + binary) cho phép dùng trực tiếp: `Config::load(&CliOverrides, path)`, `PipelineCtx::new(config, cancel)`, `agentwiki::run(&pctx)`, hoặc `scanner::scan` + `dry_run_report`. Phù hợp để nhúng vào công cụ lớn hơn hoặc thay backend bằng `MockBackend` cho test offline.

**Example Code**:

```
let overrides = CliOverrides::default();
let config = Config::load(&overrides, None)?;
let pctx = agentwiki::PipelineCtx::new(config, None).await?;
agentwiki::run(&pctx).await?;
```

**Best Practices**:

- Truyền `CancellationToken` thay vì `None` để hủy chủ động từ caller.
- Dùng `MockBackend` (qua chuỗi model `mock:*` hoặc backend tự cài đặt trait `AgentBackend`) để test pipeline không cần agent CLI thật.
- Giữ `internal_path` riêng cho mỗi repo để cache/quota không lẫn nhau.

### External tool contract

Các phụ thuộc ngoài theo hợp đồng lỏng: backend `devin|claude|codex` phải là CLI đã xác thực sẵn trong PATH (gọi `devin -p`, `claude -p`, `codex exec`); `git` tùy chọn cho `git ls-files`; `mermaid-fixer` tùy chọn cho pha verify.

**Example Code**:

```
# kiểm tra sẵn có trước khi chạy
command -v devin claude codex git mermaid-fixer
```

**Best Practices**:

- Đảm bảo agent CLI đã login subscription trước — agentwiki không quản lý xác thực.
- Nếu `mermaid-fixer` vắng mặt, hệ thống tự fallback sang heuristic nội bộ; không cần cài đặt bắt buộc.
- Với repo không phải git, đặt `scan.git_tracked_only = false` và bổ sung `excluded_dirs` phù hợp.
