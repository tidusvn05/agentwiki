# System Boundary Interface Documentation

This document describes the system's external invocation interfaces, including CLI commands, API endpoints, configuration parameters, and other boundary mechanisms.

## Command Line Interface (CLI)

### agentwiki [PROFILE]

**Description**: Default command: run the full four-stage pipeline (Preprocess → Research → Compose → Verify) to generate C4-style Markdown architecture docs for a target repository, using an already-authenticated agent CLI as the LLM backend.

**Source File**: `src/cli.rs, src/main.rs`

**Arguments**:

- `PROFILE` (string): optional - Named profile from agentwiki.toml or ~/.config/agentwiki/config.toml ([profiles.<name>] section), or a backend name (devin, claude, codex) to select that CLI's default models.

**Options**:

- `--project-path, -p`(path): optional - Repository path to document. (default: `current working directory`)
- `--output-path, -o`(path): optional - Documentation output directory.
- `--config, -c`(path): optional - Path to agentwiki.toml (defaults to <project>/agentwiki.toml). (default: `<project>/agentwiki.toml`)
- `--target-language`(enum: zh|en|ja|ko|de|fr|ru|vi): optional - Documentation language.
- `--model-efficient`(string): optional - "<backend>:<model>" string for routine tasks.
- `--model-powerful`(string): optional - "<backend>:<model>" string for heavy reasoning / retry fallback.
- `--max-parallels`(integer): optional - Max concurrent CLI calls.
- `--agentic`(flag): optional - Let the agent read the repo itself instead of embedding code in prompts. (default: `false`)
- `--no-cache`(flag): optional - Do not read or write the on-disk cache. (default: `false`)
- `--force-regenerate`(flag): optional - Ignore cached results; recompute and overwrite them. (default: `false`)
- `--skip-research`(flag): optional - Skip the research phase; load .agentwiki/research.json. (default: `false`)
- `--skip-documentation`(flag): optional - Stop after the research phase (no documentation written). (default: `false`)
- `--incremental`(flag): optional - Incremental update: no-op (0 calls) when the manifest diff is cosmetic-only; conflicts with --full. (default: `false`)
- `--full`(flag): optional - Force a full pipeline run; clears `incremental` from config. (default: `false`)
- `--dry-run`(flag): optional - Print the resolved config and task DAG, then exit. (default: `false`)
- `--verbose, -v`(count): optional - Verbose logging: -v info, -vv debug, -vvv trace. RUST_LOG env var overrides. Global flag. (default: `0 (warn)`)

**Usage Examples**:

```bash
agentwiki -p ./my-repo -o ./docs
```

```bash
agentwiki claude --target-language en --incremental
```

```bash
agentwiki devin --model-efficient 'claude:sonnet@low' --model-powerful 'claude:opus@high' --max-parallels 4
```

```bash
agentwiki --dry-run -c custom.toml
```

### agentwiki doctor

**Description**: Health-check the environment: agent CLIs on PATH, running or orphaned agent processes, .agentwiki/ state, config sanity. Read-only unless --fix is given; exits with a status code.

**Source File**: `src/cli.rs (DoctorArgs), src/doctor.rs`

**Options**:

- `--project-path, -p`(path): optional - Repository path to inspect (defaults to top-level -p or cwd).
- `--config, -c`(path): optional - Path to agentwiki.toml (defaults to top-level -c).
- `--fix`(flag): optional - Also clean up: remove a stale run.lock and leftover tempfiles. (default: `false`)

**Usage Examples**:

```bash
agentwiki doctor
```

```bash
agentwiki doctor -p ./my-repo --fix
```

### agentwiki drift

**Description**: Check generated core_dependencies claims against a statically extracted import graph. Read-only: no LLM calls, no pipeline writes, no run lock. Exit codes: 0 = ok or warnings only, 1 = --strict found new phantom/reversed findings, 2 = claims missing/invalid.

**Source File**: `src/drift/mod.rs (DriftArgs), src/main.rs`

**Options**:

- `--project-path, -p`(path): optional - Repository path to check (defaults to top-level -p or cwd).
- `--config, -c`(path): optional - Path to agentwiki.toml (defaults to top-level -c).
- `--output-path, -o`(path): optional - Documentation output dir — also searched for a committed agentwiki.claims.json.
- `--claims`(path): optional - Claims file override (default: <internal>/research.json, else <output>/agentwiki.claims.json). Relative paths resolve against the project root.
- `--baseline`(path): optional - Baseline file override (default: [drift].baseline_path in config, else <project>/.agentwiki-drift-baseline.json).
- `--max-depth`(integer): optional - Max transitive hops for `confirmed` evidence (default: [drift].max_transitive_depth = 3). (default: `3`)
- `--strict`(flag): optional - Fail (exit 1) on phantom/reversed findings not in the baseline. (default: `false`)
- `--update-baseline`(flag): optional - Write current findings to the baseline file, then exit 0. (default: `false`)
- `--export-claims`(path): optional - Export `relationships` from research.json to a commit-able file. Relative paths resolve against the project root.
- `--json`(flag): optional - Print the machine-readable report to stdout. (default: `false`)

**Usage Examples**:

```bash
agentwiki drift -p ./my-repo
```

```bash
agentwiki drift --strict --json
```

```bash
agentwiki drift --update-baseline
```

```bash
agentwiki drift --export-claims docs/agentwiki.claims.json
```

### agentwiki status

**Description**: Show documentation freshness: what changed since the last run and what the next run would regenerate. Read-only.

**Source File**: `src/cli.rs (StatusArgs), src/status.rs`

**Options**:

- `--project-path, -p`(path): optional - Repository path to inspect (defaults to top-level -p or cwd).
- `--config, -c`(path): optional - Path to agentwiki.toml (defaults to top-level -c).
- `--output-path, -o`(path): optional - Documentation output dir — selects which manifest slot to compare against (defaults to top-level -o).
- `--json`(flag): optional - Print the machine-readable report to stdout. (default: `false`)

**Usage Examples**:

```bash
agentwiki status
```

```bash
agentwiki status -p ./my-repo --json
```

## Integration Suggestions

### CLI invocation (subprocess)

agentwiki is invoked as a shell command. Scripts and CI can call it directly; deterministic exit codes (0 ok, 1 strict drift failure, 2 missing claims, 130 cancelled) support gating.

**Example Code**:

```
# CI freshness gate
agentwiki drift -p "$REPO" --strict --json > drift-report.json
# Regenerate docs nightly
agentwiki -p "$REPO" -o docs/arch --incremental
```

**Best Practices**:

- Use --json on drift/status for machine-readable output piped to other tools.
- Commit agentwiki.claims.json (via --export-claims) so CI drift checks work without .agentwiki/ state.
- Run `agentwiki doctor` first in new environments to verify agent CLIs are installed and authenticated.
- Prefer --incremental for scheduled regeneration to avoid unnecessary LLM calls.

### Configuration file

agentwiki.toml in the target repo (or ~/.config/agentwiki/config.toml globally) defines profiles, model tiers, limits, scan, verify, and [drift] settings. CLI flags override TOML which overrides built-in defaults. Profiles can also be selected as the first positional arg or by backend name (devin/claude/codex).

**Example Code**:

```
# agentwiki.toml
[models]
efficient = "claude:sonnet@low"
powerful = "claude:opus@high"

[limits]
max_parallels = 4

[drift]
max_transitive_depth = 3
baseline_path = ".agentwiki-drift-baseline.json"

[profiles.cheap]
models.efficient = "codex:mini"
```

**Best Practices**:

- Keep environment-independent settings in TOML; use CLI flags only for per-run overrides.
- Define named profiles for cost tiers rather than repeating model flags.
- Set [drift].baseline_path explicitly if the baseline file is committed elsewhere.

### External agent CLI backend

LLM inference is delegated to locally installed, pre-authenticated agent CLIs: `devin -p`, `claude -p` (JSON envelope on stdout), and `codex exec` (JSONL event stream). agentwiki constructs prompts, parses results, and handles retries/fallback via the AgentBackend trait.

**Example Code**:

```
# Backend selected via profile name or model strings
agentwiki claude -p ./repo
agentwiki --model-efficient 'codex:gpt-5-codex' --model-powerful 'devin:default'
```

**Best Practices**:

- Authenticate each agent CLI independently before running agentwiki; it never manages credentials.
- Use `agentwiki doctor` to verify the CLIs are on PATH and responsive.
- Mind the daily quota counter (.agentwiki/ state) and calls.jsonl audit log when scripting bulk runs.

### Filesystem state and artifacts

All outputs are files: generated Markdown docs in --output-path, and state under .agentwiki/ (cache, research.json, manifests, calls.jsonl audit log, run.lock). Drift consumes research.json or agentwiki.claims.json and an optional baseline JSON.

**Example Code**:

```
# Export claims for a repo where .agentwiki/ is gitignored
agentwiki drift --export-claims docs/agentwiki.claims.json
git add docs/agentwiki.claims.json
```

**Best Practices**:

- Gitignore .agentwiki/ but commit exported claims and drift baselines for reproducible CI checks.
- Use `agentwiki doctor --fix` to clear stale run.lock files after crashed runs.
- Use --skip-research to iterate on doc composition against an existing research.json without re-paying LLM cost.

### Environment variables

RUST_LOG overrides -v verbosity for the tracing EnvFilter; AGENTWIKI_E2E=1 opts in to the real-CLI end-to-end test suite for contributors.

**Example Code**:

```
RUST_LOG=agentwiki=debug,agentwiki::drift=trace agentwiki drift -p .
```

**Best Practices**:

- Prefer -v/-vv/-vvv flags for normal debugging; reserve RUST_LOG for per-module filtering.
- Only set AGENTWIKI_E2E=1 when the real CLIs are installed and authenticated.
