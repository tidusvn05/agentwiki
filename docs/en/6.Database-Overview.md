### Tables

#### `main.tasks`

Table storing the tasks of the fixture to-do application. Each row consists of an auto-increment primary key `id`, a required `title`, and a `done` completion flag (0/1). An index `idx_tasks_done` on the `done` column optimizes status filtering. The schema is created idempotently via `IF NOT EXISTS`.

| Column | Type | Nullable | Identity | Default |
|--------|------|----------|----------|---------|
| id | INTEGER | false | true |  |
| title | TEXT | false | false |  |
| done | INTEGER | false | false | 0 |

**Primary key**: id

**Source**: `tests/fixture-app/db/schema.sql`
